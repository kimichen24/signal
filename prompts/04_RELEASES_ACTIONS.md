# Codex Prompt 04 — Release Impact + Action Brief

Implement the Releases and Opportunities pages.

Release requirements:
- release records have source URL and timestamp
- seed at least one real public Codex product event/release from an official source
- compare before/after windows
- calculate new/increased/decreased/stable signals
- UI wording must explicitly communicate correlation, not causation

Opportunity requirements:
- transparent score:
  30% frequency
  25% severity
  25% growth
  20% engagement
- label as Investigation Priority
- generate Action Brief only from computed facts + evidence
- allowed action types:
  Investigate Now / Validate / Monitor / Low Priority
- product hypothesis must be labeled as a hypothesis
- suggested metrics may be generated but must not pretend actual internal OpenAI metrics are available

Add a “Why this score?” breakdown.

At the end:
- audit one release comparison
- audit one opportunity score by showing component calculations.
