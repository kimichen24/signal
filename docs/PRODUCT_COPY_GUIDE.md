# Product Copy Guide

Use:
- Investigation Priority
- AI-estimated Severity
- Emerging Signal
- Evidence
- Related feedback increased after...
- Worth further investigation
- Possible product hypothesis
- Suggested next action

Avoid:
- OpenAI should...
- This release caused...
- Root cause is...
- P0/P1 (unless explicitly labeled as Signal's internal rubric)
- Users hate...
- AI proved...
- 100% accurate
- real-time (unless actually real-time)

Tone:
- concise
- analytical
- non-dramatic
- evidence-backed
